## Key Decisions
- Build the CLI first; SwiftUI is not required for the initial milestones.
- Use a Swift Package from the outset so `BFishCore` can later be consumed unchanged by a SwiftUI macOS target.
- Use WhisperKit to transcribe speech in the source language, then pass finalized utterances to Ollama for English translation. This permits contextual prompts and terminology control.
- Do not send unstable partial transcription to Ollama. Segment speech, finalize a source utterance, then submit it with limited prior context to avoid excessive requests and constantly changing output.
- Use Swift `URLSession` against Ollama's HTTP API rather than introducing Python or a third-party Swift SDK.
- Prefer non-streaming, schema-constrained Ollama responses initially for predictable parsing; terminal streaming can be added later.
- Keep translation behind a protocol with at least `OllamaTranslator` and `WhisperTranslator` implementations so quality and latency can be compared.
- Treat BlackHole as a separately installed dependency rather than bundling it; its repository notes GPLv3/commercial licensing considerations for incorporation into non-GPL products.

## Important Context
- Working project name and CLI command are `bfish`.
- Intended Audio Hijack topology: application source branches to speakers/headphones and to BlackHole (or another virtual device); the CLI selects that virtual device as its input.
- A CLI process cannot appear as an audio input device without a Core Audio driver, so a virtual audio bridge is necessary.
- Whisper's built-in translation produces English and requires a multilingual model, not an `.en` model.
- “Real time” should initially mean stable utterance-level results every few seconds, not speculative token-by-token simultaneous translation.
- The Ollama prompt should demand translation only, preserve names/numbers/uncertainty, prohibit invention, use prior lines only for disambiguation, and return structured JSON at low temperature.
- Proposed first commands include `bfish doctor`, `bfish devices`, `bfish translate recording.wav`, and `bfish listen --device "BlackHole 2ch" --whisper-model small --ollama-model <model>`.
