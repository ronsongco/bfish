## Key Decisions
- Keep the foundation free of external dependencies so domain and CLI behavior can compile and test before WhisperKit is introduced.
- Make optional `SpeakerID` part of the initial domain model, establishing offline podcast/interview diarization as a baseline without blocking single-speaker work.
- Keep `TranslationResponse` limited to `englishText`; source text remains immutable in `RecognizedSegment` and `TranscriptTurn`.
- Use Swift concurrency and `Sendable` protocol boundaries from the start.
- Use Swift Testing for the initial test suite.
- Package the CLI inside a minimal `.app` bundle to embed permission metadata cleanly; support a configurable stable signing identity while allowing ad-hoc development builds.
- Treat `swift run bfish doctor` as a development probe and the packaged app's doctor as the authoritative permission-metadata/signing check.
