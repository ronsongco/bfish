## Key Decisions
- Continue building `bfish` rather than forking the closest Python project because a native Swift core reusable by a future SwiftUI app remains a primary goal.
- Use existing projects as references and potential dependencies, not as justification to copy code without license and API review.
- Treat Audio Hijack through Loopback or BlackHole as a supported, valuable routing path rather than the only capture method.
- Add direct system-wide and per-application capture as first-class future modes on macOS 26 using Core Audio process taps, with ScreenCaptureKit as a possible alternate backend.
- Keep the first implementation file-based; live capture follows only after WhisperKit transcription and Ollama translation work end to end.
- Make VAD, overlap, boundary deduplication, sentence assembly, bounded queues, lag reporting, and error isolation explicit architecture rather than incidental implementation details.
- Preserve source transcription when Ollama translation fails.
